# Master Project Roadmap

**Project:** EVision Telangana  
**Official Project Title:** AI-Based EV Charging Infrastructure Planning and Decision Support System for Telangana

**Version:** 1.1  
**Status:** Frozen  
**Last Updated:** July 2026

---

# Purpose

This document defines the execution strategy for EVision Telangana. It describes the project phases, daily objectives, dependencies, checkpoints, documentation workflow, presentation workflow, deployment strategy, and project milestones.

This roadmap is the authoritative implementation plan for the project and should be followed throughout development.

---

# Development Methodology

The project follows a dependency-driven development approach designed for a four-member team.

Core principles:

- Build the Minimum Viable Product (MVP) first.
- Develop modules in parallel whenever dependencies allow.
- Integrate continuously instead of waiting until the end.
- Update documentation and presentation materials every day.
- Freeze new features after Day 5.
- Record additional ideas as Stretch Goals instead of expanding the project scope.

# Project Phases

## Phase A — Foundation

**Duration:** Day 1

Objective:

Establish the complete development environment and prepare all project modules for parallel development.

Expected Outcome:

Every team member can begin independent development on Day 2.

---

## Phase B — Core Development

**Duration:** Days 2–4

Objective:

Develop every core system module and complete the Minimum Viable Product.

Expected Outcome:

A functional end-to-end system with integrated ML, backend, frontend, and AI assistant.

---

## Phase C — Integration & Validation

**Duration:** Days 5–6

Objective:

Integrate all modules, improve quality, validate results, and complete documentation.

Expected Outcome:

Presentation-ready application.

---

## Phase D — Delivery

**Duration:** Day 7

Objective:

Finalize the project, deploy if possible, rehearse the presentation, and submit deliverables.

# Risk Management

| Risk                    | Mitigation                                                        |
| ----------------------- | ----------------------------------------------------------------- |
| Low regression accuracy | Focus on explainability and feature importance                    |
| XGBoost underperforms   | Use Random Forest and document comparison                         |
| AI API unavailable      | Demonstrate fallback responses or cached examples                 |
| Integration delays      | Freeze features immediately and prioritize stability              |
| Deployment issues       | Demonstrate the application locally and document deployment steps |
